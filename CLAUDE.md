# CLAUDE.md

Project working rules for agents. Also read `AGENTS.md` (orientation, conventions, layout).

## Skills

Use **Matt Pocock skills only** (`mattpocock-skills:*`). Do not invoke `superpowers:*` skills.

Common ones here:

- `mattpocock-skills:tdd` — building any feature or bugfix, test-first.
- `mattpocock-skills:code-review` — reviewing a branch or diff before merge.
- `mattpocock-skills:diagnosing-bugs` — a failing test or broken behaviour.
- `mattpocock-skills:domain-modeling` — terminology, `CONTEXT.md`, ADRs.
- `mattpocock-skills:writing-for-agents` — editing this file, `AGENTS.md`, or a skill.
